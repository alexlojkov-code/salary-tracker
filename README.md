# Personal Finance Tracker

Personal Finance Tracker (finnest) — локальное веб-приложение для учёта личных доходов и расходов. Дашборд показывает баланс, доходы и расходы, динамику операций и распределение трат по категориям.

## Возможности

- Добавление, редактирование и удаление операций с суммой, категорией и датой.
- История операций с поиском, фильтрами и сортировкой.
- Дашборд за неделю, месяц или год. В месячном графике можно просмотреть детали каждой даты.
- Валюты UZS, USD, EUR, RUB и KZT. При смене основной валюты сохранённые суммы конвертируются по официальному курсу Центрального банка Узбекистана. Для конвертации нужен интернет.
- Интерфейс на русском, узбекском и английском языках.
- Светлая и тёмная темы.
- Операции и настройки сохраняются в localStorage этого браузера. Сервер и регистрация не нужны.

## Как запустить

1. Скачайте репозиторий через **Code → Download ZIP** или клонируйте его:

   ```sh
   git clone https://github.com/alexlojkov-code/salary-tracker.git
   ```

2. Откройте файл `index.html` в браузере.

Сборка, установка зависимостей и запуск сервера не требуются. Данные хранятся отдельно в каждом браузере и его профиле.

## Инструменты и технологии

- **HTML5** — структура приложения.
- **CSS3** — адаптивный интерфейс, светлая и тёмная темы.
- **Vanilla JavaScript** — интерфейс, операции, фильтрация, графики и логика приложения.
- **SVG** — графики динамики и расходов, формируются самим приложением.
- **localStorage** — локальное сохранение операций и настроек.
- **Intl API** — форматирование дат и денежных сумм для выбранного языка и валюты.
- **API курсов валют ЦБ Узбекистана** — используется при смене валюты; остальным функциям приложения сервер не нужен.

Исходный код приложения состоит из `index.html`, `main.css` и `script.js`.
